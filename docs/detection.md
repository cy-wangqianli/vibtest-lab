# 检测算法说明

## 1. 步态检测（Tester）

采样 `SENSOR_DELAY_FASTEST`，对三轴合成线性加速度做两路判断：

**慢通道（判步）**

1. 一阶低通：`lp += 0.35 * (linear - lp)`
2. 本底噪声：`floor += 0.004 * (lp - floor)`
3. 阈值：`thr = max(1.2, floor * 2.0)`
4. 双阈值回滞：只有 `lp < 0.6 * thr` 才重新武装，防止一个脉冲被计两次
5. 自适应去抖：`refr = clamp(lastGap * 0.5, 180, 320)` ms

**快通道（短脉冲）**

1. 原始差分：`d = linear - prevLinear`
2. 本底：`dFloor += 0.004 * (|d| - dFloor)`
3. 触发：`d > max(2.0, dFloor * 3.5)`，且距上次快通道触发 > 150 ms

两通道共用同一个去抖窗口。

### 为什么去抖要限幅 320 ms

参数扫描时发现：如果窗口按上一次间隔的 50% 无上限放大，遇到 1.9× 的异常长间隔会推出 570 ms 窗口，把下一次正常步（330 ms 后）吃掉，漏检率从 0 跳到 42%。限幅到 320 ms 后恢复。

## 2. 距离与速度

优先级：系统定位 > 广播坐标 > 步幅估算。

- GPS：相邻定位点 haversine 累加，异常点（`dt < 0.3`、`dt > 6`、`d > 30·dt + 20`）丢弃
- 步幅估算：`步数 × 步幅`，步幅取 UI 滑块值（0.5–1.4 m）
- 速度：GPS 用位移/时间；估算模式用步幅/步间隔

**坐标系**：系统定位是 WGS-84，高德瓦片是 GCJ-02。绘制前统一转 GCJ-02，推送定位前统一转 WGS-84，否则会有 300–600 m 偏移。转换算法为公开的 GCJ-02 偏移公式，往返误差 < 0.5 m。

## 3. 数据可信度评分

满分 100，扣分项：

| 检查 | 判据 | 扣分 |
|---|---|---|
| 间隔过于规律 | 20 个样本的 `dt` 标准差 < 25 ms | 40 |
| 速度过于平稳 | 速度变异系数 < 0.06 | 40 |
| 重复落点 | 位移 < 0.3 m 的点超过 4 个 | 20 |
| 速度超人类 | 平均速度 > 15 m/s | 30 |
| 位置跳变 | 单次位移 > 500 m | 40 |

分级：≥70 真实、40–69 可疑、<40 高度可疑。

**已知局限**：这三项都是统计特征，足够“像人”的模拟能拿到高分。真实反作弊会叠加设备指纹、卫星信噪比、基站/WiFi 指纹，本项目不做这些。

## 4. 仿真

`tools/sim/adversarial_sim.py` 合成加速度序列，`tools/sim/sim2.py a|b` 分别跑检出率网格和静默恢复测试。两者都只依赖标准库。

参数：100/200 Hz 采样，脉冲为抛物线包络，本底噪声 `N(0, 0.35)` m/s²。
